Déroulé du traitement

Le traitement manuel permet à l’équipe de vérifier le réseau, le paiement et la bonne destination avant envoi.

  • 2. Vous payez via OpenPay Congo au taux de 630 FCFA / USD.
  • 3. Vous envoyez votre adresse crypto ou votre ID Binance avec la capture.
  • 4. Votre commande passe en file d’attente pour validation.
